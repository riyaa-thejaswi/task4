# Python Rocket Countdown Script 🚀

A simple **Python command-line script** that executes a timed countdown from 10 down to 1 before triggering a "Blast Off" message. 

This project was written by **Riyaa** and is ideal for learning the basics of loops, the `time` module, and console outputs in Python.

## Features
* **Timed Delays:** Uses a 1-second pause between each number for a realistic countdown effect.
* **Clean Logic:** Leverages Python's built-in `range()` function to count backward efficiently.
* **Fun Output:** Concludes with an energetic visual confirmation (`Blast Off 💥🚀`).

## Prerequisites
To run this script, you only need to have **Python 3.x** installed on your computer. The script uses the standard `time` library, so no external packages or `pip install` commands are required.

## How to Run

1. **Download the script** or save the code into a file named `countdown.py`.
2. **Open your terminal** or command prompt.
3. **Navigate to the folder** where you saved the file.
4. **Execute the script** using the following command:

```bash
python countdown.py
```
